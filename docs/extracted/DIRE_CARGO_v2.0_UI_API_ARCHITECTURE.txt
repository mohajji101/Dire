⚙️ 5. SYSTEM API ARCHITECTURE
Base URL:

/api/v1




5.1 AUTH APIs
POST    /auth/login
POST    /auth/register
POST    /auth/logout
POST    /auth/otp/verify
GET     /auth/me




5.2 CUSTOMER APIs
GET    /customers
POST   /customers
GET    /customers/:id
PUT    /customers/:id
DELETE /customers/:id




5.3 SHIPMENT APIs
GET    /shipments
POST   /shipments
GET    /shipments/:id
PUT    /shipments/:id
DELETE /shipments/:id



Tracking API
GET /shipments/track/:trackingNumber



Shipment Status Update
POST /shipments/:id/status
5.4 WAREHOUSE APIs
GET    /warehouse/packages
POST   /warehouse/receive
POST   /warehouse/assign-shelf
GET    /warehouse/zones




5.5 BUY & SHIP APIs
GET    /buy-ship
POST   /buy-ship
GET    /buy-ship/:id
PUT    /buy-ship/:id




5.6 FINANCE APIs
GET    /invoices
POST   /invoices
GET    /invoices/:id
POST   /payments
GET    /payments




5.7 REPORTS APIs
GET /reports/revenue
GET /reports/shipments
GET /reports/customers
GET /reports/warehouse




5.8 NOTIFICATIONS APIs
GET    /notifications
POST   /notifications/send
PUT    /notifications/:id/read
